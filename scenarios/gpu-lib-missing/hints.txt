The GPU itself is fine; the service just cannot use it. Read the service's own log for the exact error it gives when it falls back to CPU.
The error names a CUDA library file that cannot be opened. List the folder it lives in (ls -l shows a link as NAME -> TARGET) and check whether the TARGET of that arrow really exists. Also note which version of the library IS in that folder.
Run: sudo journalctl -u analytics -n 20 (-u = this service, -n 20 = last 20 lines), then ls -l /usr/local/cuda/lib64/. Repoint the link at the file that exists: cd /usr/local/cuda/lib64, then sudo ln -sf libcudart.so.12.2.140 libcudart.so.12 (-s = a link, not a copy; -f = replace the old one). Then sudo ldconfig and sudo systemctl restart analytics.
