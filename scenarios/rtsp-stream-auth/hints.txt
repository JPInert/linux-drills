The web page loads, so the camera is reachable: this is not a cable or a switch. Ask the box's own ingest service what the camera answers it, by reading that service's log.
`sudo journalctl -u stream-ingest | tail` (-u = only this service's log, tail = the last 10 lines) shows the camera's answer. 401 means the camera got the request and refused WHO asked, not WHERE from. Compare the login in the service's config (`sudo cat /etc/stream-ingest/ingest.conf`) with the install sheet (`cat ~/install-sheet.txt`).
Prove the sheet's login with `curl -v --user nvr:PASSWORD rtsp://10.50.1.31/Streaming/Channels/101` (-v = show the camera's reply, --user = log in as user:password; 200 OK = accepted, 401 = refused). Fix the CAMERA_PASS line with `sudo nano /etc/stream-ingest/ingest.conf` (the file stays root:ingest 0640), then `sudo systemctl restart stream-ingest` and read the journal again.
