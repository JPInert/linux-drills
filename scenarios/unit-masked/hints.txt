Two separate questions for systemd: has the sync SERVICE been able to run at all, and is its 15-minute TIMER (the schedule that starts it) switched on? They are two units, each with its own state.
Try to start the service and read systemctl's exact words; `systemctl status` on the service and on the timer shows each one's state on the "Loaded:" line. There is a state stronger than "disabled" that someone sets on purpose, and a matching command that takes it off.
`sudo systemctl unmask feedrelay-sync.service` (unmask = remove the block), then `sudo systemctl start feedrelay-sync.service` to run it once now, then `sudo systemctl enable --now feedrelay-sync.timer` (--now = enable it for boot AND start it right away). Confirm with `systemctl list-timers | grep feedrelay` (NEXT = when it runs again) and `cat /var/lib/feedrelay/last-sync`.
