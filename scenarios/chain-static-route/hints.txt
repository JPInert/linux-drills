Cameras work, sensors don't, and only the box's network config changed: ask the poller what it gets, then ask the box WHICH WAY it sends traffic for the sensor network. Compare that with the install sheet.
`sudo journalctl -u sensor-poller | tail` (-u = this unit's log) shows timeouts to 10.60.0.x. `ip r` lists the routes and `ip route get 10.60.0.20` names the exact next hop the box would use: if that is the default gateway, the box has no route for the sensor VLAN, and the sheet says the default gateway does not know it.
`networkctl status eth1` shows which file configures eth1 (Network File:); read its [Route] section with `cat` (look closely at the Destination). Fix it with `sudo nano FILE`, apply it with `sudo networkctl reload` (re-reads the .network files and reconfigures), then `ip r` (the route shows "proto static" = it came from the file) and re-read the poller's journal.
