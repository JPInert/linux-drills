The service is up, so this is not "down" and not the network. Ask the box two plain questions: is anything actually using the GPU, and what does the service's own log say about why not?
nvidia-smi shows the GPU and the programs using it. The service's journal names a setting (an environment variable) that hides the GPU. It is not in analytics.conf, so ask systemd to show the whole unit file: it tells you which other file the service loads its environment from.
Run: nvidia-smi, sudo journalctl -u analytics -n 20 (-u = this service, -n 20 = last 20 lines), systemctl cat analytics (look for EnvironmentFile=), then cat that file. Delete the CUDA_VISIBLE_DEVICES line (sudo nano, Ctrl-K cuts a line) and sudo systemctl restart analytics: a running program never re-reads its environment.
