Ping works and the camera answers, so the network path is fine: "403 Forbidden" means the camera heard you and refused WHO is asking. Check this box's own identity, its IP address, against the install sheet in your home directory.
`ip a` shows the address the box really has (the "inet" line under eth0); `cat ~/install-sheet.txt` says what it should be. `ip route get 10.50.1.31` shows the "src" address, which is the one the camera sees when this box connects.
`sudo ip addr flush dev eth0` (flush = remove every address from eth0), `sudo ip addr add 10.50.0.50/24 dev eth0` (the /24 matters: it tells the box which addresses are on its local network), then `sudo ip route add default via 10.50.0.254` (the flush also removed the default route). Prove it with `curl -i http://10.50.1.31/` (-i = show the status line: you want 200 OK).
