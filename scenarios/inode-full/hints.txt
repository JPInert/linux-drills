"No space left" while the disk is mostly empty means it ran out of something other than space. Every file uses one "inode" (a slot in the filesystem's file list), and there is only a fixed number of them. df has a second mode that shows inodes.
`df -i /var/spool/frames` shows the inodes (IFree 0 = none left). Then find which folders hold all those files, how big the files are, and how old: count files, not size.
`sudo du --inodes /var/spool/frames` (--inodes = count files per folder), `ls -l` one of the old folders, then `sudo find /var/spool/frames -type f -mtime +3 | wc -l` (-type f = files only, -mtime +3 = older than 3 days, wc -l = count). Delete by AGE only, never everything: run the same find without `| wc -l` to see the list, then with -delete at the end. Re-check `df -i`.
