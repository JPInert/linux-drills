The NOC says uploads stopped, but ask the hub first: is the camera service even running, and if not, what does the hub's own log say killed it?
`adb shell ps -A | grep camerad` shows if it is running (-A = every process). `adb logcat -d | grep -i fatal` searches the hub's log (-d = print the log and stop, -i = ignore upper/lower case). The crash names a permission: check it with `adb shell dumpsys package com.facility.camerad | grep -i camera` (look for granted=true/false).
Run: adb shell pm grant com.facility.camerad android.permission.CAMERA  (give the permission back)  ;  adb shell am force-stop com.facility.camerad  (bounce it: the grant alone leaves it waiting an hour to retry)  ;  then prove it: adb shell ps -A | grep camerad  and  adb logcat -d | grep -i camera | tail -3  (want "service ready").
